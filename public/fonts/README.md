# Bundled fonts

The UI loads these variable TrueType fonts from the application bundle without network requests.

- Inter, normal, weights 100–900, downloaded from `https://raw.githubusercontent.com/google/fonts/main/ofl/inter/Inter%5Bopsz,wght%5D.ttf`. License in `Inter-OFL.txt`.
- JetBrains Mono, normal, weights 100–800, downloaded from `https://raw.githubusercontent.com/google/fonts/main/ofl/jetbrainsmono/JetBrainsMono%5Bwght%5D.ttf`. License in `JetBrainsMono-OFL.txt`.

Retrieved 2026-09-12. The full fonts retain their supplied character coverage. CSS keeps Noto and platform fallbacks for other scripts. To update, replace the local font and its matching license together, then verify both themes in the desktop WebView.
